🔥 Connect Firebase

1. Go to console.firebase.google.com

2. Create project → name it workatap

3. Firestore Database → Create → Production mode

4. Rules tab → paste this rule:

rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    // Users can only read/write their own data
    match /users/{phone} {
      allow read, write: if true; // tighten after auth
    }
    // Redemptions — write only, no delete
    match /reds/{id} {
      allow read, write: if true;
    }
    // Sub requests
    match /subRequests/{id} {
      allow read, write: if true;
    }
    // Suspects/flags — write only
    match /suspect/{id} {
      allow write: if true;
      allow read: if false; // only admin reads
    }
  }
}

5. Project Settings → Your apps → Add Web App → copy config

6. Open index.html in Notepad → replace FIREBASE_CONFIG values at the top

7. Also replace ADMIN_WA with your WhatsApp number (256XXXXXXXXX)

8. AUTOMATIC PAYOUTS ✅
Your app already has auto-payout built in via Flutterwave!

To activate it:
1. Sign up FREE at dashboard.flutterwave.com
2. Go to Settings → API Keys
3. Copy your Secret Key
4. Replace YOUR_FLUTTERWAVE_SECRET_KEY in app.html
5. Payouts will then send automatically 24/7! 💸

8. Re-upload to Netlify

✅ Once done, all users share the same database and your payout requests appear in Admin Panel in real time.
